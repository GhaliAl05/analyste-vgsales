  ## Structure du dépôt

  | Fichier | Rôle |
  |---|---|
  | `nettoyer.py` | Nettoie les données brutes selon 6 règles écrites et produit
  un journal |
  | `stats.py` | Fonctions de statistiques simples : moyenne, médiane,
  écart-type, intervalle de confiance à 95 % |
  | `outil.py` | L'outil `calculer` appelé par le modèle : une statistique sur
  une colonne de ventes, avec un filtre facultatif |
  | `arbitre.py` | L'arbitre : bloque toute réponse contenant un nombre non
  calculé par l'outil (tolérance 1 %) |
  | `agent.py` | Dialogue avec Ollama, exécute les appels d'outil, passe la
  réponse à l'arbitre, enregistre la trace |
  | `benchmark.py` | Compare le modèle seul et le système sur 10 questions à
  réponse connue |
  | `tests/` | Tests pytest (nettoyage, outil, arbitre, benchmark), sans appel
  au modèle |
  | `donnees/` | Données brutes, données propres et journal de nettoyage |
  | `traces/` | Traces JSON de vrais échanges avec le modèle |
  | `resultats/` | Résultats du benchmark (JSON complet et résumé Markdown) |
  | `ai_log/` | Journal de chaque séance et export des conversations avec Claude
  Code |
  | `EVIDENCE.md` | Les preuves de chaque brique : fichiers, commandes,
  résultats attendus, limites |
  | `CLAUDE.md` | Les règles du projet données à Claude Code |
  | `requirements.txt` | La seule dépendance externe : pytest |
